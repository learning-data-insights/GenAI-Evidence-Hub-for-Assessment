# Protocol

This folder documents how the GenAI Evidence Hub for Assessment identified, selected, and coded research papers on evaluating GenAI outputs in educational assessment.

## Pre-registered study plan

The paper selection, coding, and analysis plan was pre-registered on OSF before coding began.

Wong, A., Li, W., Andres, A., Beiting-Parrish, M., Whitmer, J., & Kurimchak, M. (2026). *GenAI Evidence Hub for Assessment: Paper selection, coding & analysis plan.* OSF. https://doi.org/10.17605/OSF.IO/AR3YG

Changes to the coding approach after pre-registration are logged in the coding sheet changelogs in [`templates/`](../templates/).

## How the protocol fits with the rest of the repository

- **Screening.** Candidate papers were screened against the selection criteria, with help from [triageQ](https://triageq.ld-insights.com). The full screening record is in [`data/`](../data/), and the paper flow diagram is in [`workflow/`](../workflow/).
- **Coding.** Included papers were coded using the Training Manual and Coding Instructions and the codebook definitions in [`training/`](../training/), with the domain coding templates in [`templates/`](../templates/).
- **Workflow.** The end-to-end study workflow is in [`workflow/`](../workflow/).
