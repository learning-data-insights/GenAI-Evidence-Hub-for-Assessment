# GenAI Evidence Hub

The GenAI Evidence Hub is a structured literature review of recent research into using Generative AI in automated scoring, item generation, and formative feedback. For more information about the study, see the pre-registration at https://osf.io/ar3yg/overview.

This repository houses the project's public deliverables: protocol documents, coding materials, the annotated dataset, templates, and reports.

- **Project website:** https://www.learningdatainsights.com/our-projects/genai-evidence-hub
- **Pre-registration (OSF):** https://osf.io/ar3yg/overview
- **Conducted by:** Learning Data Insights (LDI)

## Scope

The review covers research on generative AI in three areas of educational assessment:

1. **Automated scoring**
2. **Item generation**
3. **Formative feedback**

Research date window: papers published after 2020 and written in January 2023 or later. Full eligibility criteria are in [`protocol/`](protocol/) and the OSF pre-registration.
